## 📌 Descripción
Aplicación frontend desarrollada para apoyar la administración de inventario y activos. El proyecto organiza la interfaz en módulos para artículos, ubicaciones, traslados, reportes y administración de usuarios.

Este repositorio forma parte de mi experiencia desarrollando soluciones para optimizar procesos de registro y control de activos.

## ✨ Funcionalidades
- 🔐 Inicio de sesión.
- 📊 Dashboard de gestión.
- 📦 Gestión de artículos y tipos de artículos.
- 📍 Ubicaciones y tipos de ubicación.
- 🔄 Registro y gestión de traslados.
- 📈 Módulo de reportes.
- 👥 Usuarios, roles y permisos.
- 🧩 Administración de módulos.

## 🛠️ Tecnologías
**Angular 19 · TypeScript · Angular Material · Bootstrap · Chart.js · RxJS · SweetAlert2 · Font Awesome**

## 🚀 Ejecución local
```bash
git clone https://github.com/AnniDiaz/Fronted-InventarioUNSM.git
cd Fronted-InventarioUNSM
npm install
npm start
```
Luego abre `http://localhost:4200/`.
